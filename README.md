# sidospar

Personliga projekt vid sidan av arbetet. Publiceras med GitHub Pages på
https://kerfors.github.io/sidospar/

## Innehåll

| Mapp | Projekt |
| --- | --- |
| `kongahalla-beredskapssjukhus/` | Källgenomgång: var Kongahällagymnasiet i Kungälv planlagt som beredskapssjukhus under kalla kriget? |
| `kungalvs-kyrka-brod/` | Källgenomgång: tvättades taket i Kungälvs kyrka med ljust bröd? Med en version för barn. |
| `bohus-1678/` | Källgenomgång: sköt belägrarna in latrin i Bohus fästning 1678? Med en version för barn. |
| `kameramuseum-contax/` | Experiment: klickbar översiktsbild av Contax-skåpet i CyberPhotos kameramuseum, med data och skript. |

## Struktur

- En mapp per projekt. `index.md` i mappen blir projektets startsida.
- `index.md` i roten listar projekten. Lägg till en rad där för varje nytt projekt.
- Fristående HTML-sidor (som `bohus-1678/bajsgatan.html`) publiceras som de är.

## Bilder

Bilderna i `bohus-1678/bajsgatan.html` är utsnitt ur digitaliserade arkivhandlingar
från Riksarkivet (Krigsarkivet, SE/KrA/0425/08/097 och SE/KrA/0414/0013/0089).
Riksarkivets användarvillkor: https://sok.riksarkivet.se/om-soktjansten/anvandarvillkor/

Bilderna i `kungalvs-kyrka-brod/` är två fotografier från Riksantikvarieämbetets arkiv
(K 1 C: 34 Kungälv, nr 78 och 79), märkta Public Domain. De är förminskade från
https://pub.raa.se/dokumentation/dce231c1-ba5f-4fd2-bb65-af0e8e7bfd70 och
https://pub.raa.se/dokumentation/063c1b4a-29a6-42c8-8267-79686fffa299

Bilden i `kameramuseum-contax/contax-hyllan.html` är fotograferad av Thomas Lövgren, CyberPhoto,
och kommer från https://www.cyberphoto.se/captains-log/kameramuseum
Den används med hans tillstånd (e-post 8 oktober 2026).
