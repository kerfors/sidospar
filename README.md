# sidospar

Personliga projekt vid sidan av arbetet. Publiceras med GitHub Pages på
https://kerfors.github.io/sidospar/

## Innehåll

| Mapp | Projekt |
| --- | --- |
| `bohus-1678/` | Källgenomgång: sköt belägrarna in latrin i Bohus fästning 1678? Med en version för barn. |

## Struktur

- En mapp per projekt. `index.md` i mappen blir projektets startsida.
- `index.md` i roten listar projekten. Lägg till en rad där för varje nytt projekt.
- Fristående HTML-sidor (som `bohus-1678/bajsgatan.html`) publiceras som de är.

## Bilder

Bilderna i `bohus-1678/bajsgatan.html` är utsnitt ur digitaliserade arkivhandlingar
från Riksarkivet (Krigsarkivet, SE/KrA/0425/08/097 och SE/KrA/0414/0013/0089).
Riksarkivets användarvillkor: https://sok.riksarkivet.se/om-soktjansten/anvandarvillkor/
