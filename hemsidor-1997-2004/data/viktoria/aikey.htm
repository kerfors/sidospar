Search

Solving a problem where the basic technique being used involves examining a large number of possibilities while looking for a solution. Search graphs are often used to describe search problems. There is an initial node i, which is where the search starts, and a goal node g. The objective is to find a path through the search space that connects the initial node to the goal.

Search techniques can be classified along two dimensions: the control of processing and the types of knowledge used in the search. Two basic types of processing are forward chaining and backward chaining. Forward Chaining: start from current state and find goal, trying all possible combinations one by one. Backward Chaining (Goal Reduction): start from goal and find current state, this is possible if goal is known, and the sequence of operators is desired the types of knowledge used in the search. The basic types of knowledge used in the search are: no knowledge (blind search) types: Breadth first, Depth first, Uniform cost (branch and bound), Bidirectional, heuristic knowledge (heuristic search), and (all) other types of knowledge (knowledge-based search)

Knowledge Representation

Studies the problem of finding a language in which to encode that knowledge so that the machine can use it. The intended role of knowledge representation in AI is reduce problems of intelligent action to search problems.

Heuristic Search

Heuristic search is an attempt to search the most promising paths first. Uses heuristics, or rules of thumb, to find the best node to expand next. Relies on an evaluation function -indicates the desirability of expanding a node e.g. path cost. Given a list of nodes to be expanded, choose the one that the heuristic function estimates as the closest to the goal.

Production Systems

The first production systems were done by Newell and Simon in the 1950s. A kind of generality is achieved by using the same goal seeking mechanism for all kinds of problems, changing only the particular productions. The early production systems have grown into the current proliferation of expert system shells.

General Problem Solver (GPS)

The General Problem Solver (GPS) was a theory of human problem solving stated in the form of a simulation program (Newell and Simon). GPS was intended to provide a core set of processes that could be used to solve a variety of different types of problems.

Knowledge Acquisition

Knowledge acquisition is the transfer and transformation of potential problem-solving expertise from some knowledge source to a program. It is a generic term, as it is neutral with respect to how the transfer of knowledge is achieved.
