Programming Language - Scheme

Scheme is a functional programming language, it is a dialect of Lisp that stresses conceptual elegance and simplicity. Scheme is often used in computer science curricula and programming language research, due to its ability to simply represent many programming abstractions.

  • DrScheme (Rice Programming Language Research) is a graphical environment for developing Scheme programs
