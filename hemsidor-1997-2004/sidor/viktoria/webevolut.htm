Evolution of the web

XML minst lika viktigt som UML! Efter att ha lyssnat till och diskuterat med sex representanter från W3C, standardorganisationen bakom WWW, på ett symposium arrangerat av SICS och SISU 98-03-30, känns den slutsatsen högst relevant. Undrar du vad XML betyder och innebär? Nedan kan du läsa våra anteckningar och här hittar du också några intressanta länkar.

Det handlar inte längre om "enbart" Internet och web-teknik, utan om informationens struktur och informations system. Egentligen inget nytt, men problemen blir så uppenbara och lösningarna så nödvändig när det handlar om miljoner informations användare och de enorma mängderna information ute Internet och inne på företagens intranet. W3C är en sammanslutningen som tagit på sig och lyckats med att sätta standards på det som ofta redan funnits uttänkt och att snabbt få branschen att använda det.

Metadata - data om data

Metadata är nästa steg att knyta samman information och data om information mellan relationsdatabaser, stordatorer, lokala filer och web-servrar.

XML Extensible Markup Language. Gemensam syntax för en mängd nya dataformat, ett språk att beskriva format. Beskrivningen kallas DTD, Document Type Defintion, liknar SGML (Standard Generalized Markup Language) sätt beskriva dokument strukturer men är enklare, kompaktare och effektivare.

RDF Resource Description Framework. Nivån ovanför XML, som ger gemensamma sätt att ange betydelse och sammanhang för meta data samt för att kunna använda metadata i och mellan applikationer men också för att hitta och identifiera data m.h.a. metadata.

P3P, PICS och Dsign är exempel på nya generella standards som använder XML och är delar av ett framväxande globalt RDF. Ett gemensamt sätt att beskriva metadata för att kunna ange uppgifter om privacy, rating och signatures. För olika tillämpningsområden börjar det nu komma standards för t.ex matematisk data och kemiska formler vars struktur definierats m.h.a. XML.

Nu behövs det initiativ i olika branscher för att definiera egna metadata och utvidga de generella ramverken till att också täcka branschens begrepp. Inom sjukvården i USA har detta gjorts (HL7).

En intressant standards är SMIL -Synchronized Multimedia Integration Language - en DTD eller om man så vill "HTML för multimediaapplikationer" - för att enkelt sätta samman en multimedia presentation.

Mallar - data om presentation

Det blir än tydligare att innehåll och layout skiljs åt

CSS1 - Casacading Style Sheet, beskriver hur presentationen skall anpassas till författarens, användarens och web-läsarens önkemål om utssende och layout.

CSS2 - kommande standard som medger olika layouter beroende på media typ. Tex kan man göra en mall för layouten på utskriften och en annan på web-sidan.

XSL - Extensible Style Langage, språket för att beskriva egna mallar så att de också ingår i ett ramverk.

Information för alla

Även handikappade skall ha möjlighet att ta till sig information.

WAI - Web Accessiablilty - layout konsekvent så att de blir tolkningsbara för personer även med handikapp eller i stressade miljöer så att layouten optimeras. T.ex. uppläst text, röstnavigering, förstora texten etc. Än så länge handlar det framför allt om att följa guidelines, men på sikt skulle man i kombination med Style Sheet kunna erbjuda t.ex en alternativ vy i form av en blindtidning.

Dokument som objekt

DOM - Dokument Object Model, en plattforms- och språk oberoende gränssnitt som tillåter program att dynamiskt komma åt och manipulera innehåll, struktur och stil. Olika programspråk kommer åt de kapslade dokument som nya HTML-standarden definierar, som möjliggör det som brukar kallas dynamisk HTML. Nya HTML-standarden, 4.0 som nu är på väg, stödjer nu också UNICODE, dvs minskar problemen med olika tecken.

"A web of trust"

En av www uppfinnarna, Robert Caillian, berättade lite om www-historien från 1989 och fram till idag. Han och Tim Berners-Lee drevs av drömmarna om: A Single Universal Space - ett sätt att nå data globalt och lokalt, A Intercreativity Space - skapa gemensamma. Han återkommet till nyckelordet Trust, hur upprätthåller man och behåller man förtroende och tilltro, informations säkerhet och kvalitet.

Informations Kvalitet menade han beror på förtroendet (trust) för informationens ursprung, metadata hur väl är informationen beskriven och sist men inte minst; enkelheten att uppdatera.
